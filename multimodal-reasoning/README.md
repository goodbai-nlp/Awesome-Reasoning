# 🖼️ Multimodal Reasoning

Papers about reasoning with non-text or mixed-modality inputs and outputs. This category covers vision-language reasoning, video, audio, documents, charts, table images, 3D scenes, GUI understanding, robotics, embodied AI, and multimodal chain-of-thought.
