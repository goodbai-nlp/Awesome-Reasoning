# 🧭 Agentic Reasoning

Papers about reasoning in systems that plan, use tools, maintain memory, interact with environments, coordinate multiple agents, or solve long-horizon tasks. This category covers single-agent reasoning frameworks, tool-augmented reasoning, reflection, memory, multi-agent systems, web/OS agents, software agents, and scientific agents.
